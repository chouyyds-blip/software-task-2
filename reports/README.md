# 视障友好适配测试记录

测试于 2026 年 11 月 14 日在 Windows 11 上进行，使用 Microsoft Edge 157.0.4341.46 和 Playwright 1.62.1。测试使用新建的临时库和课程演示资料。

## 改造前

基线为从原课程项目提取后的提交 `b739bef`。Edge 无障碍树显示三个竞赛详情按钮都叫「查看详情 ↗」。搜索框具备辅助技术可访问的名称，页面上仅有输入框占位提示。正文容器设置了 `aria-live`，搜索更新时无独立的数量提示区。 [基线报告](baseline/report.json) · [基线截图](baseline/01-search-focus.png)

## 改造后

| 验证 | 操作与结果 | 证据 |
| --- | --- | --- |
| 搜索、分类、详情 | 首个 Tab 可跳到正文，搜索保留焦点，分类可用方向键选择。无结果时状态区提供文字。详情标题进入无障碍树，Esc 关闭并还原焦点。 | [搜索焦点](after/01-search-focus.png) |
| 用户与权限 | 键盘完成注册、登录、资料修改、修改密码和退出。错误密码会显示原因并聚焦错误文字。学生无发布权限。 | [登录错误](after/02-login-error.png) · [资料页](after/03-profile.png) |
| 竞赛管理 | 管理员用键盘完成发布、编辑和下架。截止时间支持直接键入，格式帮助进入无障碍树。退出后访客看不到下架竞赛。 | [发布表单](after/04-competition-form.png) |
| 高对比度 | Edge 模拟强制颜色时，当前导航、状态文字、按钮焦点和弹窗边界可分辨，键盘仍可打开和关闭弹窗。列表在 320 CSS 像素宽度无页面横向滚动。 | [高对比列表](after/05-forced-colors.png) · [高对比详情](after/06-forced-colors-dialog.png) |

[自动化结果与无障碍树样本](after/report.json)包含控件名称、角色、模态状态和日期格式说明。另通过两项 Python 回归测试，覆盖已有报名时的资格字段锁定与修改密码后其他会话失效。

启动过临时便携版 NVDA 2026.3.1。测试环境中的浏览器窗口操作因无法确认页面地址而中断，未取得能对应到项目控件的朗读证据。高对比度结果来自浏览器 `forced-colors` 模拟。
